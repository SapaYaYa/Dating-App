# Working agreement

- Do not build, implement, or change code until the user explicitly confirms.
  Always discuss and flesh out an idea with the user first, then wait for a
  clear go-ahead before writing or changing anything. Never assume a request
  to talk about a feature is a request to build it.
- Keep `docs/TESTING_CHECKLIST.md` up to date: whenever a feature is added or
  changed, add or update its test items (split by "without the server" and
  "with the server"), and un-check items whose feature changed. Keep
  `docs/GO_LIVE_CHECKLIST.md` up to date the same way.
